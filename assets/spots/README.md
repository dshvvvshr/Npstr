# Nap Spot Images

This directory contains images of nap spots shown on the map view.

## Specifications

- **Format:** JPG or PNG
- **Recommended Size:** 80x80 pixels (for thumbnails)
- **Aspect Ratio:** Square (1:1)
- **File Size:** Keep under 100KB
- **Quality:** Clear, recognizable even at small size

## Naming Convention

Use descriptive names based on location:
- `central-park.jpg`
- `botanical-garden.jpg`
- `library.jpg`
- etc.

## Current Usage

Nap spot images appear in:
- Map view spot listings
- Social posts about nap locations

## Example in HTML

```html
<img src="assets/spots/central-park.jpg" alt="Central Park">
```

Update line 110 in `index.html` to use your custom spot images.
