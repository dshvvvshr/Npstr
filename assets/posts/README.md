# Social Post Images

This directory contains images for the social feed posts.

## Specifications

- **Format:** JPG or PNG
- **Recommended Size:** 600x400 pixels (landscape orientation)
- **Aspect Ratio:** 3:2 (landscape)
- **File Size:** Keep under 500KB
- **Quality:** High-quality photos of nap spots, experiences

## Naming Convention

Use descriptive names:
- `botanical-garden-post.jpg`
- `beach-sunset-nap.jpg`
- `park-nap-spot.jpg`
- etc.

## Current Usage

Post images appear in:
- Social feed view
- Challenge/nap date submissions

## Example in HTML

```html
<img src="assets/posts/botanical-garden-post.jpg" alt="Post" class="post-image">
```

Update line 144 in `index.html` to use your custom post images.

## Tips

- Photos should be of interesting nap locations
- Good lighting and composition
- Show the environment where naps take place
- Can include people (with permission) or just locations
